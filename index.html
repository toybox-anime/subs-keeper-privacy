プライバシーポリシー — サブスク番人 (Subs Keeper)

最終更新日: 2026年10月18日

概要

サブスク番人は、氏名・メールアドレス・位置情報などの個人情報を収集しません。

  • 登録されたサブスクリプション情報(サービス名、金額、更新日、メモ)は、すべてお使いの端末内にのみ保存され、外部に送信されることはありません
  • アカウント登録は不要です
  • 広告は表示しません。広告やトラッキングのためのSDKも使用していません
  • インターネット通信を行うのは、次の「参考価格表の取得」と、ユーザーがオンにした場合だけの「任意の匿名利用統計」の2つです

権限について

  • 通知: サブスクリプションの更新日前にリマインダー通知を表示するためにのみ使用します
  • インターネットアクセス: (1) メモに記載されたURL(解約ページなど)をユーザーの操作でブラウザで開くため、(2) 参考価格表を取得するため、(3) 任意の匿名利用統計を送るため(オンにした場合のみ)に使用します

参考価格表の取得

サービスの候補と参考価格を最新にするため、アプリの起動時(前回の取得から12時間以上たっている場合)に、当アプリが GitHub Pages で公開している静的ファイル(価格表のJSON)を読み込みます。

  • この通信で、ユーザーが登録した情報や端末を識別する情報を送ることはありません
  • 通常のウェブ閲覧と同じく、通信の際にIPアドレスなどの接続情報が配信元の GitHub に届きます。その取り扱いには GitHub のプライバシーポリシーが適用されます
  • 取得できない場合(圏外など)は、アプリに内蔵の価格表で動作します

任意の匿名利用統計(オプトイン)

予測変換で「多くの人が登録しているサービス」を上位に表示するため、ユーザーが設定で明示的にオンにした場合に限り、登録したサービスのカタログ名(例: Netflix)のみを匿名で送信します。

  • 初期設定はオフです。設定画面からいつでもオフにできます
  • 送信するのはカタログに登録されたサービス名のみで、ユーザーが入力した名称・金額・日付・メモ、端末情報、アカウント情報、識別子は一切送信しません。カタログに無いサービスは送信しません
  • 送信先は、開発者が Google Apps Script で運用する集計用の受け口です。受け口はサービス名ごとの件数のみを保存し、IPアドレスや識別子など送信元を特定する情報は保存しません
  • 通信の際にIPアドレスなどの接続情報が Google に届きます。その取り扱いには Google のプライバシーポリシーが適用されます
  • 集計した件数は、予測変換の並び順(人気順)として価格表に反映する目的にのみ使用します

端末内でのアプリの有無の確認

予測変換の並び替えのため、あらかじめ定めた一部のアプリ(Netflix など)が端末にインストールされているかを端末内で確認します。インストール済みアプリの一覧を取得することはなく、確認結果を外部に送信することもありません。

データの削除

アプリをアンインストールすると、保存されたすべてのデータが削除されます。

Privacy Policy — Subs Keeper

Last updated: October 18, 2026

Overview

Subs Keeper does not collect personal information such as your name, email address or location. All subscription data (service names, prices, renewal dates, notes) is stored only on your device and is never transmitted. No account registration, no ads, and no advertising or tracking SDKs. The app uses the network only for the reference price list below and, only if you turn it on, the optional anonymous usage statistics.

Permissions

  • Notifications: used solely for renewal reminders.
  • Network access: used to (1) open URLs in your notes when you tap them, (2) download the reference price list, and (3) send optional anonymous usage statistics (only if enabled).

Reference Price List

To keep service suggestions and reference prices up to date, the app downloads a static JSON file published by this app on GitHub Pages when it starts (at most once every 12 hours). No subscription data or device identifiers are sent. As with any web request, connection information such as your IP address reaches GitHub, whose privacy policy applies. If the download fails, the built-in price list is used.

Optional Anonymous Usage Statistics (Opt-in)

Only if you explicitly turn it on in Settings, the app sends the catalog name of a registered service (e.g. "Netflix") anonymously, so that popular services can be ranked higher in suggestions. It is off by default and can be turned off at any time. Nothing else is sent: no user-entered names, amounts, dates, notes, device information, account information or identifiers. Services not in the catalog are never sent. The data goes to a collection endpoint run by the developer on Google Apps Script, which keeps only per-service counts and stores nothing that identifies the sender (no IP addresses or identifiers). Connection information such as your IP address reaches Google, whose privacy policy applies. The counts are used only to rank suggestions by popularity in the price list.

On-device App Presence Check

To rank suggestions, the app checks on-device whether a fixed set of apps (e.g. Netflix) is installed. It does not enumerate installed apps and never transmits the result.

Data Deletion

Uninstalling the app deletes all stored data.
