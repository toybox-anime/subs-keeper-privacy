プライバシーポリシー — サブスク番人 (Subs Keeper)

最終更新日: 2026年10月24日

概要

サブスク番人は、ログインしない限り、氏名・メールアドレス・位置情報などの個人情報を収集しません。任意の「クラウド同期」を使うためにログインした場合の取り扱いは、下記「クラウド同期」をご覧ください。

  • 登録されたサブスクリプション情報(サービス名、金額、更新日、メモ)は、お使いの端末内に保存されます。任意のクラウド同期をオンにしない限り、外部に送信されることはありません
  • アカウント登録は不要です(クラウド同期を使う場合のみ、Google または Apple のアカウントでログインします)
  • 広告は表示しません。広告やトラッキングのためのSDKも使用していません
  • インターネット通信を行うのは、「参考価格表の取得」、ユーザーがオンにした場合だけの「任意の匿名利用統計」、ログインした場合だけの「クラウド同期」の3つです

権限について

  • 通知: サブスクリプションの更新日前にリマインダー通知を表示するためにのみ使用します
  • インターネットアクセス: (1) メモに記載されたURL(解約ページなど)をユーザーの操作でブラウザで開くため、(2) 参考価格表を取得するため、(3) 任意の匿名利用統計を送るため(オンにした場合のみ)に使用します

参考価格表の取得

サービスの候補と参考価格を最新にするため、アプリの起動時(前回の取得から12時間以上たっている場合)に、当アプリが GitHub Pages で公開している静的ファイル(価格表のJSON)を読み込みます。

  • この通信で、ユーザーが登録した情報や端末を識別する情報を送ることはありません
  • 通常のウェブ閲覧と同じく、通信の際にIPアドレスなどの接続情報が配信元の GitHub に届きます。その取り扱いには GitHub のプライバシーポリシーが適用されます
  • 取得できない場合(圏外など)は、アプリに内蔵の価格表で動作します

任意の匿名利用統計(オプトイン)

予測変換で「多くの人が登録しているサービス」を上位に表示するため、ユーザーが設定で明示的にオンにした場合に限り、登録したサービスのカタログ名(例: Netflix)のみを匿名で送信します。

  • 初期設定はオフです。設定画面からいつでもオフにできます
  • 送信するのはカタログに登録されたサービス名のみで、ユーザーが入力した名称・金額・日付・メモ、端末情報、アカウント情報、識別子は一切送信しません。カタログに無いサービスは送信しません
  • 送信先は、開発者が Google Apps Script で運用する集計用の受け口です。受け口はサービス名ごとの件数のみを保存し、IPアドレスや識別子など送信元を特定する情報は保存しません
  • 通信の際にIPアドレスなどの接続情報が Google に届きます。その取り扱いには Google のプライバシーポリシーが適用されます
  • 集計した件数は、予測変換の並び順(人気順)として価格表に反映する目的にのみ使用します

クラウド同期(任意・ログインした場合のみ)

複数の端末(Android / iPhone / Web版)で同じデータを使うための機能です。設定画面から Google または Apple のアカウントでログインした場合に限り有効になり、ログインしなければ一切使われません。

  • 保存するデータ: 登録したサブスクリプション情報(サービス名、金額、更新日、メモ、種類など)、支払い履歴、ドル換算レート、Pro版の購入状態
  • アカウント情報: ログインに使ったアカウントのメールアドレスと、Firebase が発行する利用者ID。本人のデータを本人だけが読めるようにするために使い、他の目的には使いません
  • 保存先: Google が提供する Firebase(Cloud Firestore、データの保存場所は東京リージョン)。通信は暗号化(HTTPS)されます。Firebase の取り扱いには Google のプライバシーポリシーが適用されます
  • アクセス制御: データは利用者IDごとに分けて保存し、ログインした本人以外は読み書きできないようにサーバー側のルールで制限しています。開発者がデータを閲覧・販売・第三者提供することはありません
  • ログアウト: ログアウトすると端末とクラウドの通信は止まります。端末内のデータとクラウド上のデータはどちらも残ります
  • 削除: クラウド上のデータとアカウントの削除を希望する場合は、下記お問い合わせ先へログインに使ったメールアドレスからご連絡ください。確認のうえ削除します

端末内でのアプリの有無の確認

予測変換の並び替えのため、あらかじめ定めた一部のアプリ(Netflix など)が端末にインストールされているかを端末内で確認します。インストール済みアプリの一覧を取得することはなく、確認結果を外部に送信することもありません。

データの削除

アプリをアンインストールすると、端末内に保存されたすべてのデータが削除されます。クラウド同期を使っていた場合のクラウド上のデータは、上記「クラウド同期」の手順で削除できます。

Privacy Policy — Subs Keeper

Last updated: October 24, 2026

Overview

Unless you sign in, Subs Keeper does not collect personal information such as your name, email address or location. Subscription data (service names, prices, renewal dates, notes) is stored on your device and is never transmitted unless you enable the optional cloud sync. No account is required (you sign in with Google or Apple only if you want cloud sync), no ads, and no advertising or tracking SDKs. The app uses the network only for the reference price list, the optional anonymous usage statistics (if enabled) and cloud sync (if signed in).

Permissions

  • Notifications: used solely for renewal reminders.
  • Network access: used to (1) open URLs in your notes when you tap them, (2) download the reference price list, and (3) send optional anonymous usage statistics (only if enabled).

Reference Price List

To keep service suggestions and reference prices up to date, the app downloads a static JSON file published by this app on GitHub Pages when it starts (at most once every 12 hours). No subscription data or device identifiers are sent. As with any web request, connection information such as your IP address reaches GitHub, whose privacy policy applies. If the download fails, the built-in price list is used.

Optional Anonymous Usage Statistics (Opt-in)

Only if you explicitly turn it on in Settings, the app sends the catalog name of a registered service (e.g. "Netflix") anonymously, so that popular services can be ranked higher in suggestions. It is off by default and can be turned off at any time. Nothing else is sent: no user-entered names, amounts, dates, notes, device information, account information or identifiers. Services not in the catalog are never sent. The data goes to a collection endpoint run by the developer on Google Apps Script, which keeps only per-service counts and stores nothing that identifies the sender (no IP addresses or identifiers). Connection information such as your IP address reaches Google, whose privacy policy applies. The counts are used only to rank suggestions by popularity in the price list.

Cloud Sync (Optional, only when signed in)

Cloud sync lets you use the same data on several devices (Android, iPhone and the web version). It is active only if you sign in with a Google or Apple account from Settings; otherwise it is never used.

  • Data stored: your subscriptions (service names, prices, renewal dates, notes, type etc.), payment history, USD exchange rate and Pro purchase status.
  • Account data: the email address of the account you signed in with and the user ID issued by Firebase, used only so that your data can be read by you alone.
  • Where: Firebase (Cloud Firestore, Tokyo region) provided by Google, over HTTPS. Google's privacy policy applies to Firebase.
  • Access control: data is stored per user ID and server-side rules allow access only to the signed-in owner. The developer does not view, sell or share your data.
  • Sign-out: stops syncing; data on the device and in the cloud both remain.
  • Deletion: to delete your cloud data and account, contact the address below from the email you signed in with.

On-device App Presence Check

To rank suggestions, the app checks on-device whether a fixed set of apps (e.g. Netflix) is installed. It does not enumerate installed apps and never transmits the result.

Data Deletion

Uninstalling the app deletes all data stored on the device. Cloud data (if you used cloud sync) can be deleted as described under Cloud Sync.
