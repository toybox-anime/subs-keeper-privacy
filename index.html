プライバシーポリシー — サブスク番人 (Subs Keeper)

最終更新日: 2026年7月25日

収集する情報

サブスク番人は、ユーザーの個人情報を一切収集しません。

  • 登録されたサブスクリプション情報(サービス名、金額、更新日、メモ)は、すべてお使いの端末内にのみ保存されます
  • 外部サーバーへのデータ送信は行いません
  • アカウント登録は不要です
  • 広告は表示しません
  • アクセス解析ツールは使用していません

権限について

  • 通知: サブスクリプションの更新日前にリマインダー通知を表示するためにのみ使用します
  • インターネットアクセス: (1) メモに記載されたURL(解約ページなど)をユーザーの操作でブラウザで開くため、(2) 各サービスの参考価格表(当アプリが公開する静的ファイル)を読み取るためにのみ使用します。この通信でユーザーの情報が送信されることはありません

任意の匿名利用統計(オプトイン)

予測変換で「多くの人が登録しているサービス」を上位に表示するため、ユーザーが設定で明示的にオンにした場合に限り、登録したサービスのカタログ名(例: Netflix)のみを匿名で送信します。

  • 初期設定はオフです。設定画面からいつでもオフにできます
  • 送信するのはカタログに登録されたサービス名のみで、ユーザーが入力した名称・金額・日付・メモ、端末情報、アカウント情報、識別子は一切送信しません
  • 受け取った側はサービス名ごとの件数のみを保持し、送信元を特定する情報は保存しません

端末内でのアプリの有無の確認

予測変換の並び替えのため、あらかじめ定めた一部のアプリ(Netflix など)が端末にインストールされているかを端末内で確認します。インストール済みアプリの一覧を取得することはなく、確認結果を外部に送信することもありません。

データの削除

アプリをアンインストールすると、保存されたすべてのデータが削除されます。

Privacy Policy — Subs Keeper

Last updated: July 25, 2026

Information We Collect

Subs Keeper does not collect any personal information. All subscription data (service names, prices, renewal dates, notes) is stored only on your device. No data is transmitted to external servers. No account registration, no ads, no analytics.

Permissions

  • Notifications: used solely for renewal reminders.
  • Network access: used solely to (1) open URLs in your notes when you tap them, and (2) download a static reference price list published by this app. No user data is ever transmitted.

Optional Anonymous Usage Statistics (Opt-in)

Only if you explicitly turn it on in Settings, the app sends the catalog name of a registered service (e.g. "Netflix") anonymously, so that popular services can be ranked higher in suggestions. It is off by default and can be turned off at any time. Nothing else is sent: no user-entered names, amounts, dates, notes, device information, account information or identifiers. The receiving side keeps only per-service counts and stores nothing that identifies the sender.

On-device App Presence Check

To rank suggestions, the app checks on-device whether a fixed set of apps (e.g. Netflix) is installed. It does not enumerate installed apps and never transmits the result.

Data Deletion

Uninstalling the app deletes all stored data.
